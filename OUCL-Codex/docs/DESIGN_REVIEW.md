## 3. 仍需基线裁决的产品取舍

本次已完成可评审设计，没有把推荐方案写成APPROVED。以下合并进已有决策，不再把同一问题拆成多轮重复确认：

1. D-04/05/13/16：以1A为首版；1B/1C加载器、1D修复、候选1E导入、四期微软账户。
2. D-06/14：允许先冻结本地1A基线，将联机最终产品选择留到三期前；业务启动授权仍独立记录。
3. ADR-005/014：采用修订后的隔离例外、身份映射、恢复协议与GC规则；软链接共享方向沿用用户已给出的授权。
4. D-19 / ADR-004/015：运行游戏时关闭窗口隐藏；实际退出需先停止游戏。若将来支持退出后继续运行，必须新增独立会话监督与租约恢复方案。
5. D-20 / ADR-004：离线档案显示名与游戏名分离，具体gameName允许字符/长度由兼容测试和账户契约冻结；不以任意昵称直接充当游戏身份。
