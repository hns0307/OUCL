# S-09 共享文件与实例物化验证

状态：用户已明确授权的阶段0独立spike。使用假字节文件（扩展名.jar，不是可执行JAR），不引用正式应用路径，不下载内容、不安装依赖、不变更系统权限。方案与脚本仅验证文件系统行为，不可直接当生产实现。

## 工具与范围

- 复用现有PowerShell 7.6.5 / .NET 10.0.11；无新增或再分发依赖，新增依赖体积为0。MIT许可的PowerShell与随附.NET在本机运行，不打包进应用；未做未来应用供应链或漏洞审计，不据此选定D-18。
- 替代方案：Node/Electron适配器在工程基线批准后另验；当前不为实验安装运行时。PowerShell创建成功不能证明未来Electron API在相同权限下也成功。
- 每次在本目录 `.runs/` 创建唯一假数据目录；可指定另一个已获写权限的本地卷父目录，脚本只在其中新建唯一子目录。禁止传入UNC或含reparse point祖先的父目录。
- 测试期间对象按摘要命名，更新建立新对象，写入前复制私有化；不通过链接原地修改共享对象。
- 清理只遍历本次登记的入口，逐项校验绝对边界和父目录，不递归删除，不跟随目录联接；异常时保留不明现场并令验证失败。

## 复现

在仓库根的PowerShell 7中运行：

```powershell
& ./spikes/S-09/Invoke-S09.ps1
```

跨卷验证在同一次调用追加 `-CrossVolumeParent <另一卷上已获写权限的现有目录>`。结果文件始终写入脚本目录的 `results/latest.json`；重复运行更新该证据文件，每次fixture使用新UUID且运行后清理。未提供另一卷时跨卷场景标SKIP；链接能力不足时相关真实场景标SKIP，复制回退仍执行，绝不把跳过计为通过。脚本存在FAIL时抛出异常。

## 场景与预期

| ID | 验证 | 预期 |
| --- | --- | --- |
| C01 | 同内容不同名、同名不同内容 | 内容摘要身份明确，两个唯一对象 |
| C02 | 真实文件软链接探测 | 记录能力；失败记录异常类型并SKIP，不提权 |
| C03 | 两实例共享 | 两个入口解析为同一对象，摘要相同 |
| C04 | 只更新A | A改指向新对象，B与原对象不变 |
| C05 | 禁用/改名A | A入口改名不影响B |
| C06 | 写入前私有化 | 私有副本可改，B及原对象不变 |
| C07 | 删除实例A | 逐项移除A的已登记入口及空目录，B与共享对象仍在 |
| C08 | 注入无链接权限错误 | 明确回退Copy并记录原因，修改副本不改对象；不等于真实受限账户验证 |
| C09 | 未登记目录联接与越界 | 拒绝穿过链接写入和按受管入口删除，目标哨兵不变 |
| C10 | 断链 | 解析目标缺失被识别，不返回ready；不误删同级对象 |
| C11 | 同卷/跨卷目录联接 | 移除入口后目标哨兵与目录仍在 |
| C12 | 哈希损坏 | 同大小错误内容被拒；该检查不建立官方来源信任 |
| C13 | 中文空格路径、相似前缀、父级跳转 | 正常路径可读；根外路径被拒 |
| C14 | 真实环境的物化模式 | 探测支持则用链接；权限错误5/1314回退Copy并记录ActualPermissionDenied，其他错误直接失败 |
| C15 | 复制模式完整生命周期 | 两份副本中只更新/改名/修改/删除A，B与两个共享对象摘要保持不变 |
| CLEANUP | 清理 | 本次新建根已删除；外部既有父目录保留 |

每个卷组合独立执行C01–C15；跨卷时实例在主卷，对象在另一卷。C07只删除本实验可知的入口，不验证生产实例清单/崩溃事务；C09只验证静态链接拒绝，不证明能抵抗恶意并发替换（TOCTOU）。不验证下载去重、安装器/Mod兼容、GC、迁移、S-10或真实游戏。
