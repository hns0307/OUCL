# Mod运行环境的Java事实

生产Mod context接入InstalledJavaFacts。required major来自经校验的实例Minecraft元数据，候选只来自已登记Java记录，按与运行时服务相同的规则优先selectedJavaId及匹配的已登记major。调用现有JavaProbe重新读取真实JVM属性，事实使用本次测得完整版本；历史登记版本仅供候选筛选，不能充当证据。实际major变化则跳过该候选。

只读检查不扫描系统位置、不联网下载、不更新登记或选择、不启动游戏。没有可探测的兼容已登记Java、无Java provider或探测受控失败时返回null，规则报告保持无法判定。版本文本不能被对应加载器版本、MC版本或Java最低major替代；无法解析的实际版本仍由规则保留未知。

单个活动读取，重入返回SCAN_BUSY；每个JVM探测超时2秒、输出限制沿用64KiB、候选最多原档案32项，终止后等待子进程close。取消信号贯穿读取与探测，取消后不开始下一项。读取完成前比较完整档案快照，变化则FILES_CHANGED，不把切换前的Java结果交给新计划。没有永久版本缓存，每轮复验可以发现JVM实际升级或损坏。

该事实是当前可用的已登记运行环境观察；未来确认执行器仍须在准备和提交前复测，游戏启动仍执行既有Java复核。此服务不构成真实游戏加载验收，不代表所有缺Java环境都可自动安装Mod。
