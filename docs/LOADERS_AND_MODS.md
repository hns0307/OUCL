# 加载器与 Mod 接入记录

2026-10-25：用户明确批准四加载器及双重依赖检查，分支 mod_loaders；当前实施中，尚未交付0.3.0，未验收的能力不得宣称可用。

## 参考取舍

- KAMUCL：读取JAR声明、先计划后确认、按实际modId复验、受控文件事务；不复制源码/夹具、不采用宽容修改Maven边界、同步大文件IO或镜像元数据信任。
- XMCL：本地声明/平台来源/实例投影职责分离、项目身份去重、三态兼容、差异安装清单；core仍无IO，不引入@xmcl依赖，不吞文件异常。
- PCL：资源项目、版本与前置分离；PCL1只参考继承与身份识别，不推导现代依赖支持。

2026-10-26启动参数复核补充：再次参考KAMUCL的职责说明，确认Forge模块排除列表必须覆盖继承客户端JAR的物理文件名。OUCL在纯启动计划中为该列表使用独立受控占位符，保留游戏版本标识与脱敏预览；实现和测试独立编写，未复制参考源码。

## 目标与边界

Fabric/Quilt/Forge固定MC1.20.1 Java17、NeoForge固定MC1.21.1 Java21分别实测。元数据存在不是兼容通过；官方摘要缺失不以自行计算摘要补充上游信任。安装失败保留私有暂存，禁止发布ready。原版历史记录与现有用户数据保持；本轮新建隔离加载器实例，不原地转换。

服务端仅预留签名清单及来源接口，生产无远程入口；删除必须绑定受管旧摘要，未知Mod、存档和配置不可因清单缺项而删除。
