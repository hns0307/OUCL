# 已接纳任务的显式恢复

内部恢复与新执行共用管理器的单个根任务位置。恢复先核对原接纳、投影和事务日志，只允许已进入恢复状态的首次启动任务，随后调用绑定原目录的受保护恢复入口。事务继续核对前任账本所有权、原租约和回执方向。恢复开始后拒绝取消，关闭等待实际收尾和终态结算。已结算任务可只读返回。

测试在真实本地事务发布后模拟中断，重新打开两个持久存储后，普通运行拒绝重演，显式恢复回滚并结算同一任务。首轮恢复测试混用了两个合成签名夹具的密钥，改用原接纳计划和同一真实文件适配器后通过，原始失败保留。最终 1004 项，1000 通过、0 失败、4 项既有跳过。类型、ESLint 和构建通过。

公共恢复请求仍需持久绑定请求 ID 与原任务，应用执行入口仍取决于受信配置与后续装配。
