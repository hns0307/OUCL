## N6 分发执行

V 证明空配置产品握手与预加载调用的拒绝行为；W 验证配置后的恢复适配器、真实本地回滚与跨文档回读；X 验证主进程工厂、真实本地任务和文件事务。配置后的完整产品 Electron 验收仍待真实配置。当前执行装配在主进程启动时读取已注册根，首次选择根的实例应重启后验收。

接入材料包括发布者身份、sourceId、精确 HTTPS 发行来源和路径前缀、keyId 与 Ed25519 SPKI 公钥、一个签名的 V2 包版本、制品位置和大小哈希以及逐制品的再分发许可。若也验收原只读预览，则需要相应签名 V1 端点。当前范围为顶层 mods JAR。

首轮使用 Windows x64 独占配置、已注册根和匹配的空闲实例。依次确认配置或信任错误的拒绝行为、主进程公告与预加载、准备差异和确认前文件无变化、原 ID 重复确认只有一个任务、终态与文件哈希。恢复另用独占实例，确认原请求重复回读且玩家文件保留。证据见 [产品候选](../20261118-v/REPORT.md)、[恢复复验](../20261118-w/REPORT.md)、[配置工厂复验](../20261118-x/REPORT.md)。
