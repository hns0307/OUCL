# Fabric / Quilt 本地安装事务验证（2026-10-27）

## 范围

- 代表组合：Fabric 0.16.14 / Minecraft 1.20.1 / Java 17；Quilt 0.29.2 / Minecraft 1.20.1 / Java 17。
- 使用固定、非可执行的本地元数据与制品字节，走正式 `InstallerService`、SQLite worker、对象仓库、隔离实例物化和 `prepareLaunch` 复验路径。
- 不访问公网，不启动 Minecraft，不操作用户游戏目录。

## 已验证

- 两种加载器分别完成独立实例事务，记录加载器身份、主类、Java major、加载器 JVM 参数和隔离 `gameDir`。
- 服务关闭并重开后，强制禁用元数据读取与制品传输，仍能仅凭持久证明和已校验对象完成启动前复验；请求计数保持不变。
- 下载开始后取消会等待受控任务进入 `cancelled`，实例保持不可启动；新请求可用原显示名重新安装并进入 `ready`。
- 原有 Fabric 夹具、原版安装、共享对象复用、恢复、会话与隔离测试继续通过。

## 结果

- `pnpm check`：444 项；442 PASS、0 FAIL、2 个原有环境 SKIP。
- `pnpm typecheck`、`pnpm lint`、覆盖率门槛和 `pnpm build` 均通过。
- 完整输出：`check.log`。

## 明确保留的缺项

这些夹具证明安装编排、取消和离线重开边界，不证明真实上游当前可用，也不证明游戏主菜单、测试 Mod、正常退出或再次启动。遵用户指令，本轮跳过联网和真实游戏测试，相关矩阵继续标记未验证。
