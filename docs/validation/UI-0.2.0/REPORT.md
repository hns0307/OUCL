- 浅绿色四页顶部导航；左侧真实实例列表；首页右侧原创本地人物、离线档案切换/创建及原启动/停止流程。无真实整合包时不伪造整合包条目。

- 公告列表/分类/详情组件已建立；生产数据为空。组件支持显式preview标记用于开发示例，不接后台、不在生产注入假公告。
- 包版本0.2.0，完整便携目录及ZIP；原0.1.0和用户游戏数据保持。未push、未签名、无安装器，运行需要完整便携目录和适配Java。

## 失败与修正记录

- 首次受限执行时，原有存储测试在临时目录rename与目录链接处遭遇EPERM。改用工作区临时目录并在正常权限下运行仓库检查后通过；未降低Electron隔离、未删除owner锁。
- 第一轮官方资源样本任务失败，初始通用错误不足以确定根因；未记通过。后续增加固定脱敏错误码和可见失败记录，独立三类复测通过，不能把首次失败归咎于某个未经证明的网络原因。
- 第一轮真实UI样本失败，保留resource-ui-first-attempt.json。第二轮验收脚本把45秒未完成误当作失败并等待重试按钮；实际资源随后成功落盘，修正脚本为等待终态且只对失败终态重试。最后使用更小的FerriteCore样本，真实表单搜索、下载及切页继续全部通过；不是模拟下载。

## 边界与已知限制

Mod/光影仅下载，不安装运行组件或依赖；资源可运行性未作承诺。无公告后台、微软认证、远程皮肤或加载器新增。资源库当前最多512条记录，旧owner异常接管仍保守阻塞；中断提交保持恢复提示，不伪造完成。原阶段0/1A的完整兼容矩阵、异常owner恢复、受管Java下载等缺项继续保留。新原生Java/目录选择器复用既有能力，本轮自动化未重新操作原生选择器。
