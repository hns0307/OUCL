# Mod 安装预览绑定（2026-10-27）

## 本次增量

新增主进程私有 `ModInstallPlanner`。它不写实例、不下载依赖，也不构成玩家确认；负责把以下证据绑定为确定性、无路径/无URL的安装预览：

- 已下载根 Mod 的资源身份、平台版本、实际 SHA-1/SHA-256/SHA-512、大小及真实 JAR 声明；
- 当前实例修订、完整 Mod 文件指纹、加载器与 Minecraft 版本；
- 已装平台项目、未知来源/内嵌状态、玩家固定选择和有界依赖求解结果；
- 每个候选的项目/版本/文件摘要、大小、来源关系及 `reuse` / `library` / `download` 处置。

只有依赖图完全 resolved 时状态才为 `ready`。未知已装文件保持 `unknown`；重复 Mod ID等既有本地硬冲突、平台替换、根版本/文件摘要矛盾直接阻止预览。计划 ID 是上述公开事实的 SHA-256，不能替代确认时重新扫描和下载后真实声明复验。

## 验证

- 4 个新增测试覆盖确定性计划、依赖大小/来源链、无路径/URL输出、未知状态、平台替换、根摘要冲突、本地硬冲突、并发限制和取消加入。
- `pnpm check`：452 项；450 PASS、0 FAIL、2 个原有环境 SKIP；类型检查、lint、覆盖率门槛和生产构建通过。
- 完整输出：`check.log`。
