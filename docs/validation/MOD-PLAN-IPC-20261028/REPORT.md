# Mod 安装计划公开预览增量

日期：2026-10-28（Asia/Shanghai）。

本增量把既有 `ModInstallPlanner` 接入已批准的 `mods.v1`，新增 `mods:plan` / `planMod`。请求只包含实例 UUID、预期修订、已下载资源库的项目/版本/SHA1 身份和显式版本选择；不接受路径、URL、命令或任意文件名。响应是有界、无路径的计划，包含当前实例指纹、加载器/Minecraft、精确项目与版本、文件 SHA1/SHA512/大小、处置方式、下载总量、依赖来源链和未知/冲突原因。

主进程使用同一实例上下文、本地JAR复验、双重检查和Modrinth精确版本客户端生成计划。计划仍是非授权预览：没有持久确认、依赖下载或实例写入；preload使用35秒有界等待，超时不代表后台成功或取消。

验证：

- `pnpm check`：459项，457 PASS、0 FAIL、2个既有系统能力SKIP；typecheck、lint、coverage、build通过。
- `pnpm smoke`：34个preload方法、15项能力、renderer无Node；新增计划方法的严格入参和无游戏根错误映射通过。
- 新增契约测试覆盖路径/URL/非法选择拒绝、完整计划投影、畸形服务结果脱敏。

按用户要求未运行公网测试、未启动Minecraft、未操作用户游戏数据。下一增量仍需持久计划、玩家确认/拒绝、递归下载后真实JAR复验和一次安装事务。
